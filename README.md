## 一、独立IP 云主机是什么，和共享IP、NAT 差在哪

独立 IP 给的是使用权。服务器独占这个公网地址，域名可以独立绑定，防火墙自己配，邻居被攻击或者被平台拉黑，不会顺着 IP 烧到你身上。共享 IP 是几十个站点挤在同一个出口地址上，任何一家违规，整组跟着进黑名单。NAT 更省事，服务商连公网地址都不分给你，只做一个端口映射，平台侧看到的是机房统一出口，风控判定往往直接往数据中心流量上靠。

| 属性维度 | 独立IP | 共享IP |
| --- | --- | --- |
| 地址独占性 | 独享专属公网 IPv4 | 多用户共用同一出口地址 |
| 安全隔离 | 独立的风险隔离屏障 | 单户违规可能波及整组站点 |
| 信誉管控 | 站点信誉自主掌控 | 地址信誉由全体使用者共同影响 |
| 防护策略 | 支持自定义防火墙 | 依赖统一公共防护策略 |
| 业务适配 | 适合长期稳健运营的项目 | 适合低成本临时测试项目 |

一台云主机也能配多个地址，分主 IP 和辅助 IP、静态和动态，Linux 下加一个辅助地址就是一条 `ip addr add` 命令。多数人买独立IP 云主机用不到这一层，知道有这么回事就行。

**独立 IP 不等于原生 IP，这是最容易混的一处。** 独立 IP 说的是使用权归单一服务器独占；原生 IP 说的是 IP 注册归属地和服务器实际机房位置对得上。一台机器可以有独立 IP，但 IP 段注册在香港、机器摆在洛杉矶，WHOIS 一查地理对不上，这就叫广播 IP，平台对它的信任度会打折。独立 IP 也不等于快，速度取决于线路品质和物理距离。

再往上是住宅 IP。IP 段属于家庭宽带运营商，AT&T、Comcast、Virgin Media、Sky Broadband 这类，不在数据中心的 ASN 里，平台看到会默认是普通用户在家上网。双 ISP 指 IP 同时挂两家运营商，或者 BGP 路由归属经过两层 ISP，抗封表现比单 ISP 强一些。推广页里有句话把这三层关系说清楚了：“原生IP解决‘地理位置对不对’，住宅/双ISP解决‘像不像真人’。”这是推广文作者的总结，不是用户评价，但道理站得住。

为什么这几层属性值钱，得从 IPv4 的供给看。地址耗尽很多年了，现在市场上一个 IPv4 的转让价在 30 到 50 美元。年付十几美元的机器也能塞一个独立 IPv4 进去，靠的是整段采购、规模摊薄，代价是同一段 IP 被大量用户轮着用过，历史记录复杂，被平台标记的概率跟着上去。想要干净的住宅段，成本结构完全不同。
